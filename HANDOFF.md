# Project Overview

- **Goal:** Predict antimicrobial resistance (AMR) in *E. coli* from whole-genome assemblies using **alignment-free k-mer features + out-of-core XGBoost**, then reverse-translate the most important k-mers into biology (BLAST vs CARD/NCBI). The longer-term goal (thesis) is a **queryable, confidence-tiered, cross-antibiotic AMR k-mer Knowledge Base (AMRK-DB)**.
- **Main problem:** Turn ML feature-importance output into a *reproducible, stability-filtered, biologically validated* knowledge base — a real literature gap.
- **Current stage:** Pipeline hardened (all audit bugs fixed), refactored to **multi-organism / multi-antibiotic** architecture, **5-seed feature-stability** added, and a **BV-BRC data-acquisition stage (00/00a)** just implemented. Currently **re-acquiring the dataset** via the new download pipeline. KB layer (DB/API) not started.

# Architecture

**Data flow:**
```
BV-BRC API/CLI ─00a→ raw genome_amr + clean → genome_ids → {id}.fna assemblies
                ─00 → amr_phenotypes.csv (binary, ∩ present .fna)
 01 validate ─ 02 KMC k-mers ─ 03 sparse binary .npz chunks (+ y_*.csv, features.txt)
 04 Optuna HPO (fixed params) ─ 05 out-of-core incremental train ─ 06 eval (+bootstrap CI)
 07 Gain top-N ─ 07b 5-seed stability/Jaccard ─ 08 BLAST(CARD+NCBI) ─ 09 tiered report
```
- **Out-of-core:** 03 writes genomes in fixed-size chunks (`chunk_size=200`) as CSR `.npz`; training streams chunks (1 tree/chunk/epoch with dynamic instance weighting); 07b masks sample-level rows per chunk (one chunk in RAM at a time).
- **Config-driven:** change `config.yaml project.organism`/`target_antibiotic` and re-run. No orchestrator yet (manual sequential invocation).

# Models and Machine Learning Pipeline

- **Features:** canonical 21-mers, binary presence/absence; `min_support=5` (rare filter), max_support = n−1 (drops core-genome k-mers). `max_bin=2` (binary data RAM fix).
- **Preprocessing:** chunked CSR sparse matrices; QC outliers (02b, IQR on unique-k-mer count) excluded.
- **HPO (04):** Optuna, 25 trials, `eval_metric=auc` (from config). `colsample_bytree` searched on a **√p-anchored log range** (`compute_colsample_range`). `n_estimators = best_iteration+1` (off-by-one fixed). `scale_pos_weight` not tuned (handled by training-stage instance weighting). Writes `config/experiments/{organism}/config_{antibiotic}.yaml`.
- **Training (05):** out-of-core incremental, 1 tree/chunk/epoch, per-chunk dynamic instance weighting, `base_score=0.5` pinned (avoids pure-chunk error), trees capped at tuned budget. Threshold fixed **0.5** (no test-set tuning).
- **Evaluation (06):** single stratified split + **bootstrap 95% CIs**; PR-AUC via `average_precision_score`; **does NOT overwrite config threshold** (leakage fix). Reported test ROC-AUC (prior run): Amp 0.927, Cef 0.925, Cipro 0.990, Gen 0.930.
- **Stability (07b):** SEEDS=[42,123,777,1024,2025], stratified 80/20, fixed HPO, AUC mean±std + selection frequency + Jaccard.

# Important Decisions Made

1. **Conflict resolution** for duplicate (genome, antibiotic): **majority vote → tie: newest `testing_standard_year` → still tied: drop (NaN) + log.**
2. **Antibiotic normalisation** via registry aliases; **`co-trimoxazole` merged into `trimethoprim/sulfamethoxazole`**; canonical = registry spelling (e.g. `rifampin`, `cephalothin`).
3. **Filters:** keep only EUCAST/CLSI standards, Lab-Method evidence, Resistant/Susceptible phenotypes.
4. **HPO once, fixed across seeds** (no per-seed re-tune; leakage-safe) for 07b — "5-seed repeated holdout (Mahé 2018 resampling)", **not** true k-fold (out-of-core constraint).
5. **Phylogenetic/MLST bias** deferred to a separate later flagging step (NOT mixed into holdout splitting).
6. **07b memory model B** (fully out-of-core, one chunk in RAM).
7. **Organism-scoping** of every path incl. the auto-generated experiment config (prevents cross-organism collision).
8. **Generated outputs** (`results/`, `logs/`, `runs/`, `.npz`, `features.txt`, models) **not version-controlled.**
9. Removed non-essential viz: 03b SVD separability, 01b co-occurrence heatmap.
10. **FASTA filenames must be `{genome_id}.fna`** (pipeline globs `*.fna`, uses stem as Genome ID).
